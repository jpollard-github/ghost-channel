# Architecture

The flow is `server adapters → SourceResult[] → SignalBundle → /api/signals → IndexedDB cache → scheduler → player`. Ghost Channel owns the normalized model; NWS and USGS shapes stop inside their adapters.

The local adapter validates repository JSON and is independent of networks. External adapters bound requests, validate payloads, preserve source links, and return failed results rather than throwing through the aggregate. `loadSources` starts them together so one unavailable source cannot erase another.

`buildPlaylist` is pure, seeded, stable-ID deduplicating, priority-aware, and avoids adjacent channels whenever an alternative remains. React handles playback and diagnostics but does not understand upstream formats.

The initial page server-renders local fallback. The client prefers a fresh same-origin bundle, validates the complete bundle before replacing that fallback, persists only non-empty validated bundles, and marks a recovered cached bundle stale. One client refresh coordinator fetches on startup, ten minutes after each completed attempt, on the browser `online` event, and when the document becomes visible at least five minutes after the last successful refresh. It uses one completion-based timer and an in-flight guard, so event and timer triggers cannot overlap requests. A successful playlist replacement preserves the current stable signal ID when it remains eligible; otherwise playback restarts from the first scheduled signal. A failed refresh retains the last valid non-expired bundle.

A failed HTTP response, invalid JSON, schema rejection, and empty bundle each produce a concise diagnostics-only refresh error. Diagnostics retain the last attempt, last success, next scheduled attempt, and latest error. IndexedDB hit, empty, and unavailable states are tracked separately so a cache problem cannot obscure a server problem. Diagnostics can be opened by keyboard, query parameter, or a deliberate 1.2-second hold on the transmission-status touch target for installed displays. Procedural visuals are lightweight CSS and respect reduced motion. The service worker is a separate minimal shell fallback and does not own live data resilience. The install manifest supplies general-purpose 192px and 512px PNG icons and a separate opaque 512px maskable icon; the SVG remains a scalable fallback.

All timestamps that cross the adapter boundary are canonical UTC ISO strings. Adapters may accept source-native offset timestamps while parsing upstream payloads, but they must convert them before constructing a `Signal` or `SourceResult`. For signals, `expiresAt` is an exclusive eligibility boundary: a signal is playable only while `expiresAt` is absent or later than the current time. Expiration filtering updates both the aggregate playlist and each source's signal list while retaining the source result and health metadata. Filtering runs whenever a bundle is accepted and whenever any refresh is attempted, preventing expired signals from surviving repeated source failures indefinitely.

Extension points are new adapters returning `SourceResult`, new procedural renderers referenced by normalized media, and scheduling policy refinements. Public ArcadeGhosts data may be consumed later only through a documented public interface.
